UI / UX Design Review

Layout Suggestions for
5_26_combined.html

Evaluated for projected use — a layman leading a bilingual bible study, needing passages and questions visible simultaneously on screen.

Context Problems Found Recommendations Mockups Implementation Guide

Context

Use Case
Projected on screen or TV for a group; leader facilitates while everyone watches
Core Need
Passage text and discussion questions must be visible at the same time — no scrolling mid-question
Audience
Mixed English / Burmese speakers; bilingual side-by-side layout in use
Viewing Distance
~6–10 feet from a 55–75" display; typical small-group room or living room
⚠️

Critical mismatch: The current layout is optimized for a desktop browser reader sitting 18–24 inches away. A projected use case has fundamentally different requirements — larger type, spatial co-location of related content, and quick navigation.

Problems Found

High Priority Medium Priority Low Priority
1

Passages and questions are physically separated — never on-screen together

All five key passage cards live in Row 1. The three discussion parts (Rows 2–4) are below it. By the time Question 1 is on the projected screen, Genesis 11:4 has scrolled completely out of view. The group and leader have no reference text while answering. This is the single biggest usability failure for a projected context.

2

Font sizes are too small for projection at 6–10 feet

The body text is 18px and question/passage cards use 1.1rem (~20px). At a comfortable reading distance of 6–10 feet from a 65" display, text below ~22–24px becomes difficult to read — especially for older participants or anyone sitting at an angle. The Burmese script in particular needs generous line-height and size, as its diacritics are tightly stacked.

3

No section jump navigation — leader can't quickly find their place

The sticky bar only identifies the two language columns. There is no way to jump from the top of the page to "Part 2" or "Quotes" without manually scrolling. During a live session, if the leader needs to revisit a section or skip ahead, the entire group watches a slow scroll. This erodes the sense of control and flow during facilitation.

4

Scholar quotes are entirely detached from the questions that cite them

Questions 1, 2, 4, 5 cite Brueggemann; Questions 6, 7, 11 cite Wright; Questions 9, 12 cite Hauerwas. But the full quotes only appear in Row 5, after all 15 questions have passed. When the leader wants to share the Hauerwas quote during Q12, they must scroll down significantly — breaking momentum. The quotes are most valuable inline, near the questions that reference them.

5

Passage reference tags (q-anchor) are too small and subdued for projection

The .q-anchor span tags are 0.7rem in a muted gray — they're designed as subtle desktop metadata. On a projector screen they're essentially invisible. These tags are actually a key cross-reference tool for the leader; they should be visually prominent enough to read from across the room.

6

No full-width visual dividers between session parts

The transition between Part 1 (Babel), Part 2 (Pentecost), and Part 3 (The Church) is currently just the .movement-header inside each pair-cell column. There is no full-width landmark that spans both language columns. When projected, the group can easily lose track of which thematic section they are in. A wide section-divider banner would anchor the group spatially through the session arc.

7

Closing prayer lacks visual separation from the quotes section

Both the Voices/Quotes row and the Closing Prayer row render as identical .pair-row blocks with white cards. There is no visual cue that the session is transitioning from discussion material into a moment of worship. A subtle divider or distinctive background tint on the prayer row would signal the tonal shift.

8

No print or export stylesheet

If a participant wants a printed handout, the current page will dump cream backgrounds, dark navy headers, and drop-shadow cards — heavy on ink and low in contrast. A @media print stylesheet that removes backgrounds and increases font size to 12pt+ would make the document usable as a physical handout as well, extending its utility beyond the projected session.

Implementation Guide

🛠️

All changes are additive — no existing structure needs to be deleted. Start with the three high-priority items; they unlock the core value immediately. Medium and low items can follow in subsequent sessions.

Step 1 — High Priority

Inline Passage Repetition

  • Add id attributes to each .pair-row: id="part1", id="part2", id="part3"
  • Inside Row 2 (Part 1), copy the Gen 11:4 and Gen 11:9 .passage-card divs into both pair-cells, above .movement
  • Inside Row 3 (Part 2), copy Acts 2:4 and Acts 2:6 cards
  • Inside Row 4 (Part 3), copy Eph 2:14 card
  • Optionally add a label: <p class="section-title">Referenced Passages</p>
Step 2 — High Priority

Projection Font Sizes

  • In global_styles.css, change body font-size from 18px to 20px (safe middle ground)
  • Change .q-text font-size to 1.2rem
  • Change .passage-text font-size to 1.15rem
  • Or: add a <button> "Projection Mode" that toggles a .projection class on body with larger overrides — preserves desktop defaults
Step 3 — High Priority

Section Jump Nav

  • Add id attributes: id="passages", id="part1", id="part2", id="part3", id="voices", id="prayer"
  • Add a new <nav class="section-nav"> below the existing .lang-bar
  • Populate with <a href="#part1">Part 1: Babel</a> etc.
  • Style with position: sticky; top: [lang-bar-height]px
Step 4 — Medium Priority

Inline Scholar Quotes

  • Identify questions with scholar anchors (Q1, Q2, Q4, Q5 → Brueggemann; Q6, Q7, Q11 → Wright; Q9, Q12 → Hauerwas; Q13 → Beck)
  • After each matching .question-card, add a <div class="inline-quote"> with the relevant short quote
  • Style: navy background, gold left border, italic text, gold author attribution
  • Optional: wrap in a <details> tag to keep it collapsible
Step 5 — Medium Priority

Prominent Anchor Tags

  • In global_styles.css, change .q-anchor span font-size from .7rem to .82rem
  • Change color to var(--gold) and border to 1px solid var(--gold)
  • Add background: rgba(201,168,76,.08) for a subtle gold tint
Step 6 — Medium Priority

Full-Width Section Dividers

  • Before each of Rows 2, 3, 4, insert: <div class="full-divider"></div>
  • Style: background: linear-gradient(90deg, var(--navy), var(--navy2)), full-width, padding: 14px 32px, gold-accented text with the Part name and key scripture reference
  • No grid needed — this element intentionally breaks the two-column flow as a landmark
Step 7 — Low Priority

Prayer Row Visual Treatment

  • Add a CSS class .prayer-row to Row 6's .pair-row
  • Apply: background: rgba(15,35,64,.035) and border-top: 3px solid var(--gold)
  • This requires no structural changes — one class and two CSS rules
Step 8 — Low Priority

Print Stylesheet

  • Add @media print { … } to global_styles.css
  • Set body { background: white; color: black; font-size: 11pt; }
  • Remove box-shadow, background gradients on header, .movement-header, .quote-card
  • Set .combined-header, .pair-row, .combined-footer { grid-template-columns: 1fr; } so it prints single-column on letter paper
  • Hide .lang-bar and any nav elements: display: none
📋

Suggested order of work for next session prep: Steps 1 → 3 → 2 are the highest-leverage changes and can be done in one sitting. Together they solve the core usability problem (passage + question co-location, readability, navigation). Steps 4–6 add polish. Steps 7–8 are optional quality-of-life improvements.
